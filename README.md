## How it works

`draw.py` paints `entry.png` (1024×1024, PIL only, no network, no downloaded images, no randomness, no clock reads — two runs write identical bytes). `main.ts` is the graded entrypoint: it copies that PNG into the output directory.

```sh
python3 draw.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
